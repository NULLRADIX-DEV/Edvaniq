# Beispiele von Ereignissen

Je Ereignis und Version liegt hier eine Nachricht so, wie sie über den Broker geht: `<Service>.<Ereignis>.v<n>.json` mit allen Feldern und `<Service>.<Ereignis>.v<n>.minimal.json` mit `null` in jedem optionalen Feld. Beispiele kommen nur dazu und werden nie geändert, denn sie stehen für Nachrichten, die schon verschickt sein können; ein neues optionales Feld bringt mit der höheren Version ein neues Paar.
